# 18+ — Browser + Entertainment

A starter Android app combining a WebView browser with an entertainment-style home screen.

## Current starter features
- Self-declared 18+ entry confirmation (not identity or age verification)
- Dark home screen with category tiles
- Built-in browser with search/address bar
- Back, forward, reload and clear browsing data
- Android DownloadManager for ordinary direct downloadable file URLs
- Downloads shortcut and basic settings

## Important content and download limits
The category pages are starter placeholders. Add only content you own, have licensed, or are otherwise authorized to distribute. The app does not host, scrape, decrypt, or bypass DRM/protected streams. The Video action supports ordinary direct media file URLs only; it cannot guarantee downloads from every website, and does not support protected HLS/DASH or blob streams.

## Build APK
A push to `main` triggers **Build 18+ Android APK**. Open the repository's Actions tab, select the latest run, and download the `18-plus-browser-debug` artifact.

This is a test starter, not a production-ready browser or streaming service. Before public release, implement robust age assurance appropriate to applicable law, content licensing/moderation, privacy disclosures, secure release signing, and additional browser security review.
